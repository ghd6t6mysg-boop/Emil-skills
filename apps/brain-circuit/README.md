# Brain Circuit

A daily brain workout that takes about 10–15 minutes and never more than 30.

Open `index.html` in any browser. It's a single file with nothing to install and no build step.

## How it works

Each day gives you a circuit of 5 timed drills, one from each skill area. The drills are picked from the date, so every day brings a new mix.

| Skill area | Drills (one is picked each day) | Time |
| --- | --- | --- |
| Speed | Mental Math, Odd Shade | 2 min / 75 sec |
| Attention | Number Hunt (Schulte table), Colour Clash (Stroop) | up to 3 min / 90 sec |
| Memory | Pattern Recall, Digit Span | up to 3 min each |
| Working memory | Two Back (2-back) | 80 sec |
| Logic | Number Patterns, Word Unscramble | 2½ min each |

- Your progress is saved after each drill, so you can stop and pick up where you left off later the same day.
- Your streak, the last 14 days and your best score for each drill are stored in your browser's local storage.
- You can practise any single drill from the home screen. Practice runs don't count toward the day's score.
- On a keyboard: Enter starts or continues, keys 1–4 answer Colour Clash, and Space presses Match in Two Back.
